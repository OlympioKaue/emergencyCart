# EmergencyCart.Web

Frontend demonstrativo do EmergencyCart usando HTML + CSS + JavaScript puro.

## Telas
- Login
- Dashboard
- Setores
- Carrinhos
- Conferência

## Como executar
Pode abrir `index.html` diretamente no navegador para visualizar a interface.

Para consumir a API localmente, ajuste `API_BASE_URL` em `js/app.js`.

Exemplo:
`http://localhost:7085`
